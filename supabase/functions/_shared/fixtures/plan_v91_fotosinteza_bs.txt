UDICA                                              5 minuta
================================================================================
| Nastavnik/ca pokazuje dvije biljke: jednu zdravu, zelenu, i drugu, istu vrstu,|
| koja je rasla nekoliko dana u potpunom mraku (žuta, slaba). Također, pokazuje |
| i zatvorenu teglu u kojoj je svijeća koja gori i mala biljka. Pita učenike:  |
| 'Šta primjećujete na ove dvije biljke? Zašto je jedna zelena i zdrava, a    |
| druga žuta i slaba? A šta mislite, šta se dešava u ovoj tegli sa svijećom   |
| i biljkom? Zašto svijeća može gorjeti neko vrijeme u zatvorenoj tegli?'     |
|                                                                               |
| Cilj: stvoriti kognitivnu disonancu — učenik mora istraživati jer           |
| ne može odgovoriti bez dokaza.                                               |
| ZPD veza: ova udica aktivira prethodno znanje i otvara prostor za           |
| istraživanje koje leži unutar Zone proksimalnog razvoja.                    |

ISTRAŽIVAČKO PITANJE (mora biti otvoreno)
================================================================================
|                                                                               |
|   Kako biljke pretvaraju nevidljive stvari poput sunčeve svjetlosti i zraka  |
|   u nešto opipljivo što ih održava u životu?                                 |
|                                                                               |
| IBL nivo: Guided (L3)   |  Kognitivna faza: Concrete Operational -> Formal Operational |
| ZPD:      Srednji — pitanje je iznad samostalne zone,                       |
|           dostižno uz istraživanje dokaza i Sokratovsku podršku             |
|                                                                               |
| Provjera kvalitete (za nastavnika) — najviše 4 kratka reda s KONKRETNIM     |
| razlogom za OVO pitanje (Amandman A10), nikad niz golih "DA":               |
|   Otvoreno: Pitanje traži objašnjenje složenog procesa pretvaranja, a ne jedinstven odgovor "šta je". |
|   Traži istraživanje: Učenici ne mogu odgovoriti bez analize ulaznih i izlaznih elemenata i njihove uloge. |
|   ZPD: Izazovno je razumjeti transformaciju "nevidljivog u opipljivo" za 5. razred, ali dostižno s dokazima. |
|   Vodi dalje: Otvara pitanja o tome šta se dešava s hranom i kako to utiče na druge organizme. |

ISHODI UČENJA

| CILJ UČENJA: Učenici će istražiti proces fotosinteze kako bi razumjeli kako |
| biljke koriste sunčevu svjetlost i plinove iz zraka za stvaranje hrane i kisika. |
|------------------------------------------------------------------------------|
| I1  Učenik može opisati ključne sastojke (vodu, ugljikov dioksid, sunčevu   |
|     svjetlost) potrebne za fotosintezu, koristeći slikovne dokaze. Dokaz:   |
|     Tok časa, popunjavanje dijagrama "Šta ulazi i izlazi". Nivo: Razumijevanje |
| I2  Učenik može objasniti ulogu sunčeve svjetlosti u procesu pretvaranja    |
|     ugljikovog dioksida i vode u hranu, na osnovu analize podataka. Dokaz:  |
|     Brzi izlazni produkt. Nivo: Analiza                                     |
| I3  Učenik može ilustrovati kako fotosinteza doprinosi opstanku biljaka i  |
|     proizvodnji kisika za druge organizme, kreirajući jednostavan dijagram.|
|     Dokaz: Brzi izlazni produkt. Nivo: Stvaranje                            |

|   [ ] Mogu nacrtati jednostavan dijagram kako biljke prave hranu i kisik.  |

VIZUELNI ELEMENT 1: Šta ulazi i izlazi iz biljke?
--------------------------------------------------------------------------------
| Služi istraživačkom pitanju:                                                 |
|   Pomaže učenicima da vizuelno prate put "nevidljivih stvari" (svjetlost,   |
|   CO2, voda) i vide šta biljka proizvodi kao "opipljivo".                   |
|                                                                               |
| Opis: Dijagram procesa sa strelicama koji prikazuje ulazak sunčeve         |
| svjetlosti, vode i ugljikovog dioksida u list, te izlazak kisika. U sredini|
| lista, diskretno, stoji 'stvaranje hrane'.                                  |
|                                                                               |
| ASCII prikaz:                                                                 |
|                                                                               |
|   +------------------------------------------+                               |
|   | TITLE: Šta ulazi i izlazi iz biljke?     |                               |
|   |                                          |                               |
|   |  SUNČEVA SVJETLOST                       |                               |
|   |         ^                                |                               |
|   |         |                                |                               |
|   |   VODA  >-----> [ LIST BILJKE ] <----- UGLJIKOV DIOKSID |               |
|   |         |                                |                               |
|   |         v                                |                               |
|   |       KISIK                              |                               |
|   |                                          |                               |
|   |  (Unutar lista: stvaranje hrane)         |                               |
|   | Tool: hand-drawn with labels / textbook  |                               |
|   +------------------------------------------+                               |
|                                                                               |
| Kako koristiti u ovoj lekciji:                                               |
|   Uvesti nakon čitanja teksta o sastojcima. Zamoliti učenike da popune       |
|   praznine ili opišu strelice. Koristiti uz Sokratovo pitanje 1.            |
|                                                                               |
| Gdje pronaći / napraviti:                                                    |

--------------------------------------------------------------------------------
|  POJAM                  | DEFINICIJA (prilagođena uzrastu)                  |
|-------------------------|---------------------------------------------------|
|  Fotosinteza            | Proces kojim biljke, uz pomoć sunčeve svjetlosti, |
|                         | vode i zraka, stvaraju vlastitu hranu i kisik.    |
|  Sunčeva svjetlost      | Energija sa sunca koju biljke koriste kao "gorivo"|

|                         | hrane, a koji je neophodan za disanje ljudi i     |
|                         | životinja.                                        |
|  Klorofil               | Zelena supstanca u biljkama koja upija sunčevu    |
|                         | svjetlost.                                        |
|  Hrana (biljna)         | Šećer koji biljke same proizvode i koriste za    |
|                         | rast i energiju.                                  |

UVODNI DIO — UDICA I ISTRAŽIVAČKO PITANJE     5 minuta
--------------------------------------------------------------------------------
|  0-5 min:                                                                    |
|  Postavite dvije biljke (jedna zdrava, jedna žuta od mraka) i teglu sa      |
|  biljkom i zapaljenom svijećom na vidno mjesto. Započnite razgovor pitanjima|
|  iz udice. Fokusirajte se na zapažanja učenika i prirodnu znatiželju.       |
|  NE objašnjavajte fotosintezu niti šta se dešava sa svijećom. Cilj je       |
|  stvoriti zagonetku.                                                        |
|                                                                               |
|  Nakon udice, postavite istraživačko pitanje: "Kako biljke pretvaraju       |
|  nevidljive stvari poput sunčeve svjetlosti i zraka u nešto opipljivo što  |
|  ih održava u životu?" Zamolite 2-3 učenika da prepričaju pitanje SVOJIM    |
|  riječima kako biste provjerili razumijevanje. Aktivirajte prethodno znanje |
|  o tome šta biljkama treba za rast (voda, sunce), ali bez dubljeg          |
|  objašnjenja procesa.                                                       |
|                                                                               |
|  ZPD SAVJET: Ovo pitanje je postavljeno iznad zone samostalnog znanja,      |
|  ali unutar zone dostizne uz dokaze. Ako učenik odmah zna odgovor,         |
|  pitanje je prenisko — prilagodite dokazni materijal ili razgovor.         |
|                                                                               |
|  VAŽNO: Ne odgovarajte na učenička pitanja o sadržaju.                      |
|  Recite: "Odlično pitanje — upravo zato istražujemo."                       |
================================================================================

SREDIŠNJI DIO — ISTRAŽIVANJE                  20 minuta
--------------------------------------------------------------------------------
|  Organizacija učenika:                                                       |
|  Podijelite učenike u grupe od 4-5. Svaka grupa dobija jednu kopiju teksta  |
|  "Šta biljkama treba za rast" i jednu kopiju ilustracije "Razmjena plinova |
|  kroz list". Uputite ih da pažljivo pročitaju tekst i analiziraju         |
|  ilustraciju.                                                               |
|                                                                               |
|  Uvođenje dokaznog materijala:                                              |
|  Instruirajte grupe da prvo pročitaju tekst, a zatim da koriste informacije|
|  iz teksta i ilustracije da popune dijagram "Šta ulazi i izlazi iz biljke?"|
|  (Vizuelni element 1) i tabelu "Biljka u mraku vs. Biljka na svjetlu"      |
|  (Vizuelni element 2) na tabli.                                             |
|                                                                               |
|  Koristite Sokratova pitanja u ovim momentima:                              |
|    Nakon 15 min (nakon prvog kruga čitanja i popunjavanja):                 |
|      "Gledajući dijagram i tekst o sastojcima, kada kažemo da biljka       |
|      'stvara hranu', šta pod tim tačno podrazumijevamo? Da li je to kao da |
|      mi jedemo sendvič?"                                                    |
|    Nakon 25 min (nakon popunjavanja tabele i diskusije o svjetlosti):       |
|      "Ako biljka ne dobije dovoljno sunčeve svjetlosti, šta nam to govori  |
|      o ulozi sunca u pretvaranju 'nevidljivih stvari'? Gdje to vidimo u    |
|      našoj tabeli i dijagramu?"                                             |
|                                                                               |
|  Facilitation — NE dajte odgovore. Obilazite, slušajte, postavljajte Q.    |
|  Budite spremni da usmjerite učenike da obrate pažnju na strelice na       |
|  dijagramu i da povežu žutu boju biljke sa nedostatkom sunca, a ne samo     |
|  'bolesti'. Pobrinite se da se svaki učenik u grupi uključi.                |
================================================================================

ZAVRŠNI DIO — DIJELJENJE I REFLEKSIJA         15 minuta
--------------------------------------------------------------------------------
|  Dijeljenje nalaza (10 min):                                                 |
|  Pozovite po jednog glasnogovornika iz svake grupe da predstavi svoje       |
|  zaključke, koristeći popunjene dijagrame i tabele. Ohrabrite ih da objasne |
|  'kako' su došli do svojih zaključaka. Nastavnik/ca vodi diskusiju,         |
|  postavljajući pitanja koja traže dokaz i koja podstiču poređenje među     |
|  grupama. NE potvrđujte niti opovrgavajte odgovore, već tražite dodatne    |
|  dokaze.                                                                    |
|                                                                               |
|  Sintezno Sokratovsko pitanje (Tip F) (1 min):                               |
|  "Na osnovu svega što ste pronašli danas — kako biste sada odgovorili na   |
|  naše istraživačko pitanje: 'Kako biljke pretvaraju nevidljive stvari      |
|  poput sunčeve svjetlosti i zraka u nešto opipljivo što ih održava u       |
|  životu?' I šta biste još željeli znati da biste bili još sigurniji u svoj |
|  odgovor?"                                                                  |
|  Ovo pitanje VODI NAZAD na IQ i otvara meta-kognitivnu refleksiju.         |
|                                                                               |
|  Uvođenje dokaza učenja (8 min):                                            |
|  Podijelite "izlazne kartice". Objasnite zadatak: nacrtati jednostavan      |
|  dijagram i u jednoj rečenici objasniti zašto je sunčeva svjetlost ključna.|
|  Naglasi da je to prilika da pokažu šta su SAMI otkrili.                     |
|                                                                               |
|  Refleksija učenika (2 min):                                                 |
|  Na samom kraju časa, pozovite učenike da razmisle o pitanjima za refleksiju |
|  (može usmeno ili kratka pisana bilješka). Podsjetite ih na kriterije uspjeha.|

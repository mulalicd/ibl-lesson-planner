## New Rules
- **E-22 Stored content is never regenerated by the AI; additions are appended** 🔴 CRITICAL — an AI asked to
  rewrite a saved document to "include" something lost a whole section once (UDICA) and reduced a requested rubric to
  one sentence (S06, Director catches ×2); a section rewrite reported success on an empty card (S05). Rule: AI output
  that adds to stored content is appended deterministically (numbered amendments); a replacement, if unavoidable, is
  checked for completeness against what it replaces, shown before saving, and the old text is kept for a one-click
  restore. Evidence: `corrections/SPRINT_06_LESSONS.md` ("Ugradi u plan" ×2), SPRINT_05 #12, DL-P37.
- **E-23 Zero-tolerance output rules are enforced after generation, measured on what the user sees** 🟡 STANDARD —
  prompt instructions reduced German plans copying Bosnian template lines from 3/13 to 1/7 but never to 0 (S05 #11);
  Markdown leftovers, rule lines and spaced dashes reached the screen (S06). A deterministic display layer reached 0.
  Evidence: SPRINT_05 #11, SPRINT_06 "leftovers on screen", DL-P19, DL-P30, DL-P36.
- **E-24 Lazy-loaded SPAs survive a release while open** 🟡 STANDARD — an open tab asked for the previous release's
  chunk after a merge; the SPA catch-all rewrite answered with HTML ("MIME type text/html", Word export failed, S06).
  Rule: reload once on the bundler's chunk-load error event (rate-limited), never rewrite `/assets/*` to
  `index.html`, and preload the opened route's chunks so on-demand pages add no round trip. Evidence:
  SPRINT_06 "page opened before a release", PR #47, S6 perf table.
- **E-25 Source shared by two runtimes uses runtime-neutral imports; every CI step runs locally before push**
  🟡 STANDARD — a Vite-only `@/` alias in a file also imported by the Deno eval script failed CI (S06, PR #48); the
  Deno binary disappeared after a worker restart and tests ran through a shim (S05). Rule: relative imports with
  explicit extensions in shared files; the pre-push check runs all CI commands (Deno through `npx -y deno@2`).
  Evidence: SPRINT_06 "Deno-shared file", SPRINT_05 gotcha "worker restart removed deno".
- **C-13 Show the owner results, not stages; every screen and state verified at the owner's screen size**
  🔴 CRITICAL — four Director catches in one phase: an intermediate stage shown as the result, a whole screen left out
  of a "total" redesign, an overlap visible only at 1920 px, a feature that worked but looked inactive (S06); a false
  "success" and test steps taken from a fixture (S05). Rule: before asking for approval, a route × state × viewport
  inventory (including the owner's own screen size and the shortest step of each multi-step screen) with screenshots
  and console checks; a success message only after the visible result is checked; owner test steps come from real
  production output. Evidence: SPRINT_06 Corrections 1–3, SPRINT_05 #12.

## New Decision Log Entries
- **DL-020 — Vite SPA + Supabase Edge Functions as the whole backend** — for a small school tool, Edge Functions
  cover the Application layer (authenticate → authorise → Zod → execute) without an Express server; RLS carries
  authorisation (project DL-P01, P1 matrix 51 checks, P6 live check 8/8).
- **DL-021 — Free-tier Gemini with a per-key model fallback and a key-health check** — rotate keys, fall back to the
  next model on the same key on 503/404, and run a one-request-per-key health check (labels only, duplicate
  detection) before any quota diagnosis (project DL-P14, DL-P18; S05 #5–6: only 5 of 12 keys served the model).
- **DL-022 — Official letterhead Word export from the institution's own template** — patch the owner's `.dotx`
  (converted once, metadata stripped) with `docx` `patchDocument`, keeping headers, footers and images byte for byte;
  every export of the app uses the same builder (project memorandum decision, S06 M-7 correction).
- **DL-023 — Institution colour system enforced on the BUILT CSS** — restrict the Tailwind palette to the brand
  colours plus neutrals and fail CI on any other colour in `dist/**/*.css` (preflight brings its own greys and ring
  colour); self-host OFL fonts (project DL-P33; S06 gotcha "Tailwind's base styles").
- **DL-024 — Owner-approved user guide as an in-app page with real screenshots** — open before sign-in, steps in the
  order of the work, screenshots produced by the same Playwright script as the checks, so they are renewed with the
  UI (project DL-P38; complements DL-019).
